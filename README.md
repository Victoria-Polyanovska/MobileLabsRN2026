Для запуску даного мобільного застосунку необхідно виконати кілька послідовних кроків у терміналі. Спочатку потрібно перейти до кореневої папки проєкту та виконати команду npm install для завантаження всіх необхідних пакетів. Фінальний запуск середовища розробки здійснюється командою npx expo start, після чого додаток можна відкрити на мобільному телефоні через сканування QR-коду в додатку Expo Go або у веб-браузері натисканням клавіші w.
Реалізований функціонал застосунку охоплює всі ключові етапи роботи сучасного інтернет-магазину. Користувачеві доступний повноцінний каталог товарів із візуальним відображенням, текстовим описом та актуальною ціною, де кожна позиція може бути додана до кошика одним натисканням. У самому кошику впроваджено гнучку систему управління замовленням, що дозволяє миттєво змінювати кількість обраних одиниць товару або видаляти окремі позиції з автоматичним перерахунком загальної вартості. Процес купівлі завершується заповненням спеціальної форми оформлення, де система перевіряє коректність введення контактних даних, таких як ПІБ та електронна пошта. Після успішного підтвердження кошик автоматично очищується, а всі деталі замовлення зберігаються в окремому розділі історії.
що таке глобальний стан у React Native? Глобальний стан у React Native являє собою централізоване сховище даних, яке дозволяє обмінюватися інформацією між різними компонентами додатка незалежно від їхнього розташування в дереві навігації. Використання такого стану вирішує проблему складної передачі даних через багато рівнів вкладеності та забезпечує синхронізацію інтерфейсу, наприклад, коли зміна кількості товару в кошику на одному екрані має миттєво відобразитися на іншому.
для чого використовується Redux Toolkit? Для ефективного керування глобальним станом використовується Redux Toolkit, який є офіційним набором інструментів для роботи з Redux. Він був створений для того, щоб спростити написання коду, позбутися складних налаштувань та забезпечити стандартні практики розробки, що робить процес програмування швидшим та менш вразливим до помилок.
яке призначення createSlice? Ключовим інструментом у цьому наборі є функція createSlice, яка призначена для опису логіки окремих частин стану, наприклад, кошика або списку товарів. Вона дозволяє в одному місці визначити початкові дані, назву слайса та набір функцій-редюсерів для оновлення цих даних, при цьому автоматично генеруючи відповідні екшени для виклику цих оновлень.
для чого використовується configureStore? Для збирання всіх створених слайсів у єдину систему використовується функція configureStore. Її основним призначенням є створення головного сховища додатка, де вона автоматично об’єднує різні редюсери, підключає необхідні допоміжні інструменти для розробки та налаштовує систему так, щоб додаток міг коректно опрацьовувати всі зміни даних у реальному часі.
для чого використовується redux-persist? Для того, щоб дані не зникали при кожному закритті програми, використовується бібліотека redux-persist. Вона призначена для автоматичного збереження вибраних частин глобального стану у постійну пам'ять мобільного пристрою через AsyncStorage та їх відновлення при наступному запуску, що забезпечує безперервність роботи користувача з його кошиком або історією замовлень.
