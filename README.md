 Лабораторна робота 1. Мобільний застосунок "FirstMobileApp"
Поляновська Вікторія Едуардівна, група ІПЗ-24-2(2)

Додаток створено на базі фреймворку React Native та інструментарію Expo. Він має три екрани: головну сторінку зі стрічкою новин, фотогалерею у вигляді сітки зображень та сторінку профілю з формою для реєстрації користувача.

Для запуску проєкту потрібно відкрити термінал, зайти в робочу папку командою cd FirstMobileApp, та запустити сервер командою npx expo start. Після цього з'явиться QR-код для тестування, який треба відсканувати на телефоні, а перед цим завантажити expo go.

Тестувати цей додаток можна декількома основними способами. Перший спосіб через безкоштовну програму Expo Go на власному смартфоні. Це найшвидший варіант побачити роботу наживо, просто відсканувавши QR-код. Другий спосіб це використання віртуальних емуляторів на комп'ютері. Третій варіант — запуск прямо у веббраузері.
