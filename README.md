Лабораторна робота 2 Поляновська Вікторія ІПЗ-24-2

Для запуску застосунку потрібно відкрити термінал у кореневій папці проєкту та виконати команду npx expo start. Оскільки на моєму телефоні програма чомусь не працює, я тестувала та відкривала цей проєкт у браузері на комп'ютері. Для цього, після того як у терміналі з'являється QRкод, потрібно просто натиснути клавішу w, і застосунок автоматично запуститься у новій вкладці браузера.


У цій лабораторній роботі було реалізовано:
 Вкладену навігацію: Drawer Navigator містить у собі Stack Navigator.
 Головний екран  із відображенням списку новин за допомогою оптимізованого компонента FlatList.
Екран деталей із динамічним заголовком, куди передаються параметри вибраної новини.
Екран контактів із відображенням згрупованих даних за допомогою компонента SectionList.
Кастомізоване бокове меню  з відображенням профілю.


Висновки (Контрольні запитання)
1. Чим відрізняється FlatList від ScrollView?
Звичайний `ScrollView` рендерить одразу всі елементи, що перевантажує пам'ять. `FlatList` використовує механізм віртуалізації для ефективної роботи з великими масивами даних.

2. Що таке віртуалізація списків?
Це механізм оптимізації, за якого рендеряться лише видимі на екрані елементи. Невидимі елементи видаляються з пам'яті, а їхні компоненти перевикористовуються під час прокрутки.

3. Як здійснюється передача параметрів між екранами?
Параметри передаються як об'єкт під час виклику функції переходу. На цільовому екрані вони отримуються через об'єкт `route.params`.

4. Що таке вкладена навігація?
Це архітектура, коли один навігатор міститься всередині іншого (наприклад, `Stack Navigator` всередині `Drawer Navigator`).

5. У яких випадках застосовується SectionList?
Він застосовується для відображення групованих даних, коли список потрібно поділити на категорії із власними заголовками.
