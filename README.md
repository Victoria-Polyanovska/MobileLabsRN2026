На початковому етапі ми налаштували проект у Firebase, де створили веб-застосунок, активували автентифікацію через Email/Password та розгорнули базу даних Firestore. У самому коді ми ініціалізували Firebase через окремий конфігураційний файл, налаштували збереження сесій та створили захищену структуру навігації з використанням груп маршрутів. Реалізований функціонал дозволяє новим користувачам реєструватися, існуючим — входити в систему або скидати пароль через пошту, а також керувати особистим профілем, зберігаючи та редагуючи ім'я, вік і місто безпосередньо у хмарній базі даних. Ми також забезпечили можливість повного видалення акаунту разом із пов'язаними даними та налаштували правила безпеки Firestore, які обмежують доступ до інформації, дозволяючи кожному користувачу бачити та редагувати лише свій власний документ. У результаті ми отримали повноцінний застосунок із захищеним доступом та синхронізацією даних у реальному часі.
Скріншоти програми надано в окремій папці.
