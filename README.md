Лабораторна 4. Поляновська Вікторія ІПЗ-24-2

Оскільки на моєму мобільному виникли технічні проблеми з роботою додатка Expo Go, запуск і тестування застосунку розглядаються через веб-браузер ноутбука. Для цього терміналу було виведено команду запуску, а після появи меню вибору платформи натиснути клавішу «w» на клавіатурі. Після успішної компіляції додаток автоматично відкривається у вкладці браузера.

Цей застосунок це мобільний файловий менеджер, створений на React Native . Його головна задача, дати користувачу можливість керувати своїми документами прямо в телефоні або браузері. Завдяки використанню компонента FlatList, вміст поточної директорії відображається у вигляді чіткого та зрозумілого списку, де кожний елемент має свою унікальну іконку залежно від типу. Навігація в додатку реалізована через динамічний заголовок, який постійно показує шлях користувача від кореневої папки до вкладених розділів. Система дозволяє легко переходити всередину обраної директорії або повертатися на рівень вгору, забезпечуючи повну свободу пересування файловою системою. Для створення нових елементів, таких як папки або файли формату .txt, використовуються спеціальні модальні вікна з полями для введення назви, що робить процес інтуїтивно зрозумілим і швидким.
